## GitHub — README Description

# LED ON/OFF Circuit – KiCad

A beginner PCB design project created using **KiCad 9**, demonstrating the complete process of designing a simple LED circuit and converting it into a PCB layout.

## Circuit

The circuit consists of:

* **R1:** 330Ω resistor
* **D1:** LED
* **J1:** 2-pin connector
* **Supply:** +5V
* **Ground:** GND

The resistor is used to limit the current through the LED.

## Design Workflow

1. Circuit schematic creation
2. Electrical Rules Check (ERC)
3. Component footprint assignment
4. PCB component placement
5. PCB routing
6. Design Rules Check (DRC)
7. PCB 3D visualization
8. Gerber and drill-file generation
9. Gerber output verification

## KiCad Files

The repository contains the editable KiCad project files:

* `.kicad_sch` — Schematic
* `.kicad_pcb` — PCB layout
* `.kicad_pro` — KiCad project configuration

## Project Goal

The goal of this project was to learn and practice the complete **schematic-to-PCB workflow in KiCad 9**, including PCB layout, routing, and design-rule verification.

**Software:** KiCad 9
**Project Type:** PCB Design / Electronics
